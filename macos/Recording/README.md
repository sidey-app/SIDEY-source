# SIDEY 릴스 촬영 도구

지원하는 촬영 앱은 **sidey-reals** 하나다. macOS 26 이상에서 로그인·서버 연결 없이 실제 SpriteKit 캐릭터, 말풍선과 투척을 재생한다. 앱은 화면이나 마이크를 녹화하지 않는다. macOS의 영역 녹화로 촬영한다.

## 실행

최신 main 검토는 저장소 루트에서 `python3 scripts/skills/workflow.py open --scheme sidey-reals`를 실행한다. 작업 중 미리보기는 `--preview <worktree 절대경로>`를 추가한다. 프로젝트·scheme·소스·실행 프로세스·편집 창 준비 상태를 확인한 뒤 열림을 보고한다.

Xcode 수동 작업은 `macos/Recording/SIDEYRecording.xcodeproj`의 `sidey-reals` scheme을 사용한다. Debug의 빌드 없는 실행도 현재 소스와 빌드 출처 검사를 통과해야 한다. 기본 `SIDEY` 앱과 프로젝트를 혼동하지 않는다.

배포하지 않는 독립 Release 앱은 `macos/Recording/build_reals.command`로 만든다. 결과는 같은 폴더의 `dist/sidey-reals.app`에 놓인다. 이 프로젝트에는 Supabase·Sparkle 패키지 또는 본 앱 타깃 의존성이 없다. 공유 렌더러·값 모델·화면 잠금 확인·픽셀/음원 리소스만 직접 참조한다.

## 촬영과 설정

- 출연자 1~12명, 이름·캐릭터·대사·대사 간격·준비 시간·말풍선 수명·마지막 유지 시간·오버레이 폭을 편집한다.
- 기본 예제는 기존 유저1/2/3 대화 20줄이다. 텍스트 가져오기는 `유저1: 대사`, `2: 대사`, `이름: 대사` 형식을 지원한다. 모호한 중복 이름은 번호로 지정한다.
- 액션 구간에서 펄스나 투척을 추가한다. 잘못된 출연자 참조·시점·중복 액션은 재생 전에 검사한다.
- 재생/일시정지/처음부터를 사용한다. 일시정지하면 대사와 투척의 가상 시계도 함께 멈춘다. 편집 창을 닫거나 종료하면 오버레이·타이머·음원을 정리한다. 화면 잠자기는 일시정지하고 화면 구성이 바뀌면 정지한다.
- 편집 내용은 기존 `app.sidey.reals` 설정 영역을 그대로 사용한다. JSON 파일로 저장·불러오기도 가능하며, 자동 저장이 불가능하면 그 상태를 표시한다. 미완성 대사도 초안으로 보존한다.

이전 `SIDEYReels` Debug 도구와 기존 작업 폴더는 이 통합에서 자동 삭제하거나 실행하지 않는다. 촬영 설정은 Git·빌드 캐시·작업 폴더 정리 대상이 아니다.

## 검증

`scripts/macos/tests/test_recording.sh`는 편집/가져오기/설정 보존, 액션 시점, 일시정지·재개, 재시작·종료 정리와 실제 렌더러를 검사한다. `test_native.sh`도 이 검사를 호출한다. 새 공유 리소스를 추가할 때는 전용 프로젝트의 명시적 참조를 함께 추가한다.
