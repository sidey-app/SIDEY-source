# 코드 공개 라이선스와 에셋 기여 경계

Status: Superseded
Superseded by: [비공개 source와 공개 배포 저장소 분리](202609202255-private-source-public-distribution.md)
Decided: 2026-09-17 18:25 KST

## Context

외부 코드 기여를 받으면서 수정본의 소스 제공 조건과 상업적 이용 범위를 명확히
정해야 한다. 코드를 공개하는 선택이 유료 캐릭터 등 콘텐츠의 재사용 허락이나
외부 에셋 접수를 의미해서는 안 된다.

## Decision

사용자는 기존 기여분의 동의·권한을 확보했다고 확인하고, 이 저장소의 SIDEY 소스
코드에 GNU AGPL version 3 only를 적용하기로 했다. 정확한 조건은 루트
[`LICENSE`](../../LICENSE), 적용 범위와 별도 권리는
[`LICENSING.md`](../../LICENSING.md)에 둔다. 새로운 코드 기여도 같은 조건으로
받으며, 기여자의 저작권을 양도받거나 별도 독점 배포권을 취득한 것으로 간주하지
않는다.

외부 에셋 기여는 받지 않는다. 에셋 제출 안내와 전용 PR 절차는 운영하지 않으며,
기존 에셋의 이용 제한·저작자 표시·계약은 보존한다. 유지관리자의 기존 에셋 수정은
일반 PR과 기존 자산 검증 절차를 따른다.

## Consequences

소스 코드의 상업적 이용은 AGPLv3 조건을 따르며, 수정·배포·네트워크 이용에 해당
라이선스가 요구하는 의무를 적용한다. 브랜드와 비코드 에셋은 별도 권리 범위를
유지한다. 공개 코드의 이용권을 서비스 이용약관으로 다시 제한하지 않는다.

이 변경은 과거 배포본의 허락을 소급해서 철회하거나, 별도 비공개 backend·운영
저장소에 라이선스를 부여하지 않는다. 새 앱 배포 시 포함된 코드·의존성·에셋의
권리와 해당 스토어의 배포 조건을 별도로 확인한다.
