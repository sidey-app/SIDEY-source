# Historical SIDEY Sparkle feed

`appcast.xml` is retained only as a historical record of the retired macOS Direct
distribution channel. Current SIDEY builds do not read or publish this feed; macOS updates
are delivered only through the Mac App Store. Never edit or republish the signed historical
feed by hand. Its former release and download URLs were intentionally removed and no longer
resolve.

The former Direct release, notarization, Sparkle appcast and Homebrew Cask scripts have been
retired and removed. Do not recreate them from this document or use an old checkout to
publish a new Direct release. Historical Direct GitHub Releases, assets and tags were deleted;
existing customer account, message and purchase records remain intact.

The retired private signing key is not stored in this repository. Preserve it only according
to the operator's encrypted offline backup and access-retention policy; this repository does
not authorize exporting, rotating or deleting it.
